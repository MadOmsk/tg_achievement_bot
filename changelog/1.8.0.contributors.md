# 1.8.0 — notes for contributors

## Version

- A new minor: bump `TRUNK_LINE` to 8 on `prerelease`, merge into `main` locally, tag `v1.8.0`, push the tag first, then `main` (CLAUDE.md → Releases).
- Ten migrations, D becomes `087`: 078 (the person tables point at `users(id)`), 079 (`users.email`, `email_codes`), 080 (`notify_push`/`notify_telegram`, `notifications`, `push_subscriptions`), 081 (`user_settings.notify_posts`), 082 (`invites`), 083 (`users.email_prompted_at`), 084 (`game_patches.kind`, `image_url`), 085 (posts keep their time; both reset `steam_apps.patches_checked_at` so every app is read again), 086 (`guide_channels`, `guide_videos`, `guide_marks`), 087 (`user_settings.notify_push_on`, `notify_telegram_on` — the kinds each channel carries, none by default — and `notify_game_news`). **Rehearse them on a copy of production before the merge** — 078 rebuilds tables with foreign keys off.

## Configuration

- New, optional: `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURITY` (`starttls` / `ssl` / `none`), `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM`. No mail server, no email sign-in — and then nobody new can sign up in a browser at all, since that takes an email or the Login Widget. Setting it up: `docs/mail-setup.md`.
- New, optional: `YOUTUBE_API_KEY` — a first-run seed like the Steam and Anthropic keys; the admin panel owns it afterwards (/admin → Keys, and the Mini App's). Without it there are no video guides.
- `EMAIL_LOG_CODES` and `EMAIL_SKIP_CODE` are for the dev server only; the second is ignored, with an error in the log, whenever `SMTP_HOST` is set.
- Push needs `MINI_APP_URL` (where a tap opens) and a contact (`SMTP_FROM`, else the https app address). The VAPID key pair is made on first use and kept encrypted in `app_settings` (`vapid_private_key`) — never regenerate it, or every subscribed browser is orphaned.
- BotFather `/setdomain` must name the Mini App's host on each bot, or the Login Widget does not render.

## Backend

- **Person id everywhere** (#156): repo, services, pollers, the publisher and the Xbox login take `users.id`; a Telegram id is resolved once at a Telegram door. `/admin`'s buttons carry `p<person id>`; a bare number from an old button is still a Telegram id.
- **Email sign-in** (#162): `services/email.py` (`EmailSender`, SMTP or the log), `services/email_login.py` (codes as HMACs keyed from `FERNET_KEY`, 10 minutes, 5 tries, one a minute and five an hour per address), `web/mini_logins.py`.
- **Merging two people** (`services/merge.py`, `db/repo/_merge.py`): one transaction with foreign keys deferred to commit; a super-admin's Telegram is never the one dropped.
- **Invites** (`services/invites.py`, `web/mini_invites.py`, `db/repo/_invites.py`): a new person in a browser answers `invite_required` with a `signup` token kept in memory 15 minutes; `POST /api/mini/auth/signup` finishes it. Inside Telegram nobody needs one.
- **Notifications** (#164): `services/notifier.py` (`Notifier.notify`, `KINDS` with `telegram` and `game`), `services/webpush.py` (RFC 8291 + VAPID on `cryptography`, tested against the RFC's example). New post notices go from `Publisher.on_new_post` in a background task, by the follower's `notify_posts`, at most once per author and game in three hours.
- `ensure_user` stores exactly the username Telegram sent: `None` clears a stale one.

## Mini App

- `components/shared/lib/back-stack` (`useBackHandler`): one history entry per open layer, pushed when it opens and never re-armed after a back (Chrome skips entries added without a gesture); `BackHead`, `Sheet`, the game page, person pages and tabs register. A layer reusing a component passes `layer`.
- One text field (`.field`, `.field-note`, `.btn.is-wide`, `.form-stack` in `base.css`); settings rows that open screens start with `RowGlyph`; `MonthChipSkel` is the chip's own label, invisible, so the header never shifts.
- **News and the post pages**: `components/club/news-feed` (`GET /api/mini/club/news`, `repo.games_news`); a post's or a patch's page is `components/game/news-page/NewsPage`, an achievement's `components/game/achievement-page/AchievementPage` — both portalled over everything, on `components/game/post-page/PostPage.css`, an achievement's rarity and points at the head's right through `BackHead`'s `aside`, a post's kind on its date line. A game's «Обновления» holds news and patches, filtered at the tab's right. A row on the game page opens its achievement's page now; the tip no longer unfolds in the list.
- **Pictures**: `shared/lib/img-ratio` (`useImageRatio`, remembered in `localStorage`) gives a feed post its picture's shape within 4:5–1.15:1, `isWide` puts the text under a wide one; `FitImg` gained `mode="contain"` and `top`. `shared/lib/image-viewer` (`openImage`, one `ImageViewerHost` in the shell) is the one full-screen picture, faces included. `steam_news.plain_text` keeps a post's pictures as address lines, a linked one too.
- `shared/lib/haptic.ts` (`tick`): the dock's tap — Telegram's haptics only with real Init Data (its script defines the object in any browser), else `navigator.vibrate`, else iOS's `switch` checkbox.
- **Video guides** (`services/youtube/`, `poller/guide_videos.py`, `db/repo/_guides.py`): TrophyTom's channel read once through its history (~220 pages, 8 a tick), then its newest page every 6 hours; matched to achievements on reading, by exact normalized name inside the game's own videos. `/guides` answers `videos` beside `tips`.
- The PWA: `public/manifest.webmanifest`, `public/sw.js` (pushes only, no offline cache), `apple-touch-icon.png`; the install banner is `shared/lib/install-prompt`.
- The brand: `public/logo.svg` is the source; the PNGs are rendered from it.
