# 1.4.4 — notes for contributors

## Version

- **No trunk line bump** (owner's call). `TRUNK_LINE` stays `4`, no tag: production reports `1.4.4.062` — one more first-parent, non-documentation commit on `main` since `v1.4.0`. Working branches keep reading `1.5.x`.
