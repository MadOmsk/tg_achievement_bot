# 1.8.4 — notes for contributors

## Version

- A patch release: `TRUNK_LINE` stays 8, no migration (D stays `089`), no new dependency. Bot only.

## Bot

- `web/mini_api.py::steam_identity`: `POST /api/mini/connect/steam` reads `steam_id` (what the Mini App has sent since 2026-09-25) and, for older clients, `identity` — as PSN's connect reads `online_id` and `identity`. Reading only `identity` answered every Mini App attempt with 400 `missing_identity`.
- `repo.cached_names` / `cached_descriptions` read the catalog per game in `IN` batches of `CATALOG_BATCH` (500) through `_catalog_rows`; one `OR` per achievement made SQLite refuse a game of ~1000+ achievements ("Expression tree is too large"), which killed a whole Steam backfill. `SteamFetcher.backfill` now logs and skips any one game's failure, not only `SteamApiError`.
- `repo.admin_users()` returns every person, no game account required; `views/admin._icon` marks a person with none 🔘. Ordered excluded last, then by last online (never online after), newest first. `AdminStatus.users` counts them too.
