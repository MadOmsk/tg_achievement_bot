# 2.2.0 — notes for contributors

## Version

- A minor release: `TRUNK_LINE` 1 → 2, tagged `v2.2.0`; migration 138 (D is `138`); no new dependency.

## Database

- One games database (#229): the catalog's tables (`db/repo/_games_db.py::CATALOG_TABLES`) live in a file both bots `ATTACH` as `games`, named in a database's own `app_settings` (`games_db_path`). Unqualified names resolve to it; what creates a catalog table, index or trigger is placed in `games` (`placed`) for schema.sql, the migrations and the indexes after them. A named file that is missing stops start-up.
- **A migration touching the catalog runs once per server against the shared file: additive and idempotent only.** A rework that rebuilds or drops a catalog table parts the two (`xbox-deploy games leave`) for its duration. See CLAUDE.md.
- Scripts open and copy databases through `bot/db/files.py` (`connect`, `open_database`, `backup`), which attach the games file; a copy is made of both.
- `scripts/games_db.py split|join|leave [--dry-run]`; `octopus_take` takes a queue entry in one statement and holds it 30 minutes.
- 138: `versions.description_source`, `description_ru_of` (#230).

## Bot

- `services/game_descriptions.py` (#230): a game page opened in Russian with no Russian story starts one background Haiku translation of the English shown (a version's or HLTB's), kept with a hash of that English. `_stores.native_ru` keeps a store's Russian only when it is Cyrillic and not its English.
- `x360_frame`: the store's 720×1080 poster loses its white band (126 px); `game_page.store_art` marks a 360 product's store poster. `scripts/collect_x360_addons.py` searches the add-ons of every 360 game with a store page not searched yet.

## Operations

- `xbox-deploy games split|join|leave [--dry-run]` replaces `xbox-deploy catalog`; a deploy's backup copies the games file too (`<copy>.games.db`, pruned with it).
- With this release prod joins the shared file: `sudo xbox-deploy games join --dry-run`, then without. The test server split already (`/srv/unlocked-games/games.db`).
- Port 22 is closed (#228); the old picture caches are in `/var/tmp/old-media-20261028` until deleted (#227).
