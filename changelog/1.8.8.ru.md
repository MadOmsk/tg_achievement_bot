# 1.8.8 — хотфикс — 23 октября 2026

**Русский** · [English](1.8.8.en.md)

Хотфикс: порядок на сервере. Для участников чатов ничего не меняется.

## Для суперадмина

- **Сервер хранит только свежие копии базы.** Раньше каждое обновление сохраняло копию базы и не удаляло старые — они заняли почти весь диск. Теперь остаются 8 последних на основном сервере и 5 на тестовом.
- **Обновления выкатываются через защищённый порт.** Вход на сервер — только по ключу.
