# 1.5.0 — notes for contributors

## Version

- **A new minor: `TRUNK_LINE` 4 → 5, tag `v1.5.0`** on the release merge. Production reports `1.5.0.062`; working branches read `1.6.x` once they take `main`.
- **#129 was first merged straight into `main`**, which deployed it at once as `1.4.5.062` and announced a version with no notes behind its link. This release combines #129, #130, and #131 cleanly into 1.5.0. `changelog/1.4.5.*` points to 1.5.0 for the link that announcement carried.
- **The merge is made locally, tag pushed before `main`** (as for 1.4.0): the deploy counts C from the newest tag it fetches, and a tag added after a GitHub merge would arrive after the deploy.
- **No migrations** — D stays `062`.

## Mini App (#129, #131)

- `webapp/src` is split into `components/`, `screens/`, `api/` and `i18n/` (strings only in the locale files); styles and constants are shared, CSS sits next to its component.
- **New dependency: `swiper`** (carousels, stock creative effect). Dots keep their own state so a slide change does not re-render the carousel; backdrop blur is off inside carousels.
- The game page is its own scroll layer, so pull-to-refresh and the sheet's touch lock no longer swallow it. Day jumps: `useDayJump` / `DayPicker`. The feed renders the first five posts and more as the bottom nears.
- Profile: games of the month (`PlayedGames`) with cover art, progress bar, last unlock date; recent achievements carousel (`RecentPosts`).
- Game page: glowing effects and platinum badge for 100% completions, uncropped descriptions, hiding secrets by user setting.
- Unified progress bar with 25/50/75% marks and glowing fill; PSN tier medals.
- Skeleton loaders instead of spinners. Inter font. Account deletion via Telegram native popup.

## Server (#129, #131)

- `GET /api/mini/games/{platform}/{title_id}?tg_id=` returns another member's progress only when the caller shares a chat with them (403/404/400 otherwise). Game details rewrite `icon_url` to https like the feed, and report the platform's real `achievements_total` plus `catalog_partial` when the stored catalog is shorter.
- `repo.chat_ultra_rares()` — the month's finds under 0.5% for the stats screen, rarity from the catalog first.
- `TitleCatalogService`'s PSN refresh called a repo method that does not exist (`active_link_of`); it uses `get_platform_link`.
- `bot/poller/daily.py`, `bot/poller/publisher.py`: on a test bot (`is_test()`), an unreachable chat only logs and skips in memory instead of deactivating it in the database — preventing the test bot from emptying its chat list when running against a production dump.
- `services/release_notify.py`: on the test bot a "chat not found" only logs — it runs on a copy of production's database and is not a member of those chats, and deactivating them emptied the copy's chat list and the Mini App on every version bump.

Tests: `tests/test_mini_game_person.py`, `tests/test_chat_ultra_rares.py`, `tests/test_publisher.py`, `tests/test_release_notify.py`.
