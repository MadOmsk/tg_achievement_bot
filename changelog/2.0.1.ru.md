# 2.0.1 — хотфикс — 28 октября 2026

**Русский** · [English](2.0.1.en.md)

Хотфикс: аватарки в Telegram, картинки игр с нашего сервера, обложки Xbox 360 без рамки.

## Приложение

- **Аватарки снова видны внутри Telegram.** В приложении, открытом из Telegram, вместо лиц показывались инициалы: картинка запрашивалась без подписи Telegram, и сервер её не отдавал. Теперь лица загружаются как надо, и открываются на весь экран со страницы человека.
- **Постеры, обложки и баннеры игр приходят с нашего сервера.** Раньше приложение тянуло их прямо из магазинов Xbox, Steam и PlayStation. Теперь сервер один раз скачивает картинку, уменьшает её до разумного размера и дальше отдаёт сам: быстрее и не зависит от чужих серверов.
- **Обложки игр Xbox 360 без рамки.** У портретной обложки отрезана шапка «XBOX 360» (и её варианты: Platinum Hits, Games for Windows LIVE, ARCADE), у квадратной — зелёная полоса слева. То же в постах в чатах.

## Для суперадмина

- **Каталог игр переносится с тестового сервера на прод одной кнопкой.** GitHub → Actions → Catalog. По умолчанию это пробный запуск: всё делается на копии базы прода и печатается итог, прод не трогается. Без галочки каталог прода заменяется тестовым (перед этим — резервная копия), бот на минуту останавливается. Кнопку можно нажимать сколько угодно раз.
- **Метки и веса каталога приезжают с каждым релизом** из папки `catalog/` в git; если они не менялись, ничего не происходит.
