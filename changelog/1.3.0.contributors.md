# 1.3.0 — notes for contributors

What changed in `1.3.0` across PR #87, TitleHub fixes, and automated release
announcements.

## Trunk line bump to 3

- `bot/version.py`: `TRUNK_LINE` bumped from `2` to `3`. Production on `main`
  reports `1.3.*`, and working branches / test bot report `1.4.*`.
- Tagged with `v1.3.0` on `main`.

## Release announcements (`bot/services/release_notify.py`)

- Broadcasts update notifications to all active group chats (`chat_id < 0` and
  `is_active = 1`).
- Uses `app_settings.last_announced_version` to ensure announcements are sent
  exactly once per version upon startup.
- Production attaches an inline button linking to GitHub changelog files:
  `https://github.com/MadOmsk/tg_achievement_bot/blob/main/changelog/1.3.0.<locale>.md`.
- Test bot announces to its test chats without buttons or links.
- Handles `TelegramForbiddenError` by deactivating kicked chats via
  `repo.deactivate_chat(chat_id)`.

## Mini App HTTPS icons & layout improvements (PR #87)

- Enforced HTTPS schemes for game icons in `webapp/src/` and backend models to
  prevent mixed-content image blocking in iOS / Telegram WebViews.
- Enhanced styling for achievement cards, secret cards, and carousels in
  `webapp/src/styles.css` and `webapp/src/ui.tsx`.

## TitleHub response resilience

- In `bot/services/xbox/client.py`, handled `ValidationError` when parsing
  `TitleHubResponse` as a cache miss instead of raising, preventing poller
  crashes on upstream payload anomalies.
