# 1.8.2 — notes for contributors

## Version

- A patch release: `TRUNK_LINE` stays 8. One migration, D becomes `089` (`passkeys`). **Rehearse it on a copy of production before the merge.**
- A new dependency, `webauthn` (py_webauthn) — the deploy reinstalls dependencies because `pyproject.toml` changed.

## Backend

- `services/passkeys.py` (`Passkeys.for_app(MINI_APP_URL)`: origin and RP id from the app's https address; challenges in memory, five minutes, spent by any answer), `web/mini_passkeys.py` (`/api/mini/me/passkeys[...]`, `/api/mini/auth/passkey/verify`), `db/repo/_passkeys.py`. `/auth/email/start` with `passkey: true` answers an address that has keys with their options and sends no mail. A merge moves the keys.
- Tests: `tests/test_passkeys.py` signs with a software authenticator (a real P-256 key, CBOR, signature), so py_webauthn checks what a browser would send.

- A game news notice keeps `appid` and `gid`; the list answers `news`, a push's URL `n=appid:gid`; `GET /api/mini/club/news/post` gives one post (and its game with `title_id`).

## Mini App

- `shared/lib/passkey` (JSON ↔ WebAuthn buffers), `components/me/logins/PasskeysGroup`, the sign-in screen asks for the key and falls back to the code.
- `shared/lib/wordmark/Wordmark`: the U and "nlocked" in Nunito ExtraBold (`public/fonts`, seven letters, 1.3 KB). `logo-splash-512.png` is the manifest's 512 `any` icon (Android's launch splash); `logo-maskable-512.png` carries a smaller U.
- `.fr-icons` sits flush with a row's right edge; `.post-page-pic` takes the full width.
- `NewsPostLoader` opens a post known by its app and id (the bell, a push's `n=`); a pushed post opens alone, its game a tap on its head.
