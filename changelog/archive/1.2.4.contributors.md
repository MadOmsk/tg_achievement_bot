# 1.2.4 — notes for contributors

What changed between the initial `1.2.0` release and `1.2.4` across PRs #83,
#84, #85, and #86.

## CI/CD and deployment pipeline (#4)

The deployment and testing model is now fully codified:

- **`.github/workflows/ci.yml`**: runs on every push and PR. Executes `ruff format --check`,
  `ruff check`, `pytest`, and `npx vite build --base=/app/` inside `webapp/`.
- **`scripts/xbox-deploy.sh`**:
  - Always dumps a dated SQLite backup to `/var/backups/xbox-bot/` prior to `git pull`.
  - Reinstalls dependencies via `uv pip sync` / `pip install` only if `pyproject.toml` changed.
  - Extracts the pre-built `webapp/dist/` artifact to `/var/www/xbox-mini/` (or `/var/www/xbox-mini-test/`).
  - Restarts `xbox-bot` (or `xbox-bot-test`) via systemctl and monitors journalctl for the
    startup confirmation log line bounded by the pre-restart timestamp.
  - Performs `git fetch origin --tags` to keep version tracking up to date.

## Second web origin for test bot

- Test bot has its own nginx virtual host at `test.xbox.sultanpharm.com/app/`
  pointing to `/var/www/xbox-mini-test/` and proxying `/api/mini/` to 127.0.0.1:8081.
- Because Telegram Mini App `initData` is validated against `BOT_TOKEN`, test and
  production instances cannot share an API backend or origin.

## Version computation (`bot/version.py`)

- **B (line)**: derived dynamically via `line()`. `main` resolves to `TRUNK_LINE` (`2`),
  any other branch resolves to `TRUNK_LINE + 1` (`3`). No constants need manual editing
  upon merge.
- **C (revision)**:
  - On `main`, counts `--first-parent` commits from the newest tag matching `v[0-9]*`
    (`git describe --tags --abbrev=0 --match "v[0-9]*"`). Each merge into main increments
    the release counter by 1 regardless of how many branch commits were merged.
  - On working branches, counts all commits since the merge base with `BASE_REFS` (`origin/main`, `main`).

## Catalogue backfill

- Added `scripts/backfill_title_names.py` with test coverage in `tests/test_backfill_title_names.py`.
- Populates missing Xbox `titles` rows and `platform` columns using live Xbox Title Hub
  lookups, querying only via active tokens to avoid authentication error cycles.
