# 1.8.9 — notes for contributors

## Version

- A hotfix: `TRUNK_LINE` stays 8, no migration (D stays `089`), no new dependency.

## Steam

- `IPlayerService/GetRecentlyPlayedGames` carries no `rtime_last_played` (checked live, 2026-10-25; only `GetOwnedGames` has it), so `RecentlyPlayedGame.last_played` was always 0 and `poller/steam_catch_up.py` dropped every game against its cutoff — the hourly Steam catch-up never polled anything for anybody. A game whose last play is unknown is now always polled (1–5 games an account an hour). The 24-hour publish window is unchanged.
