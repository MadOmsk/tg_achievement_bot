# 1.8.7 — notes for contributors

## Version

- A hotfix: `TRUNK_LINE` stays 8, no migration (D stays `089`), no new dependency.

## Bot

- `services/achievement_icons.py`: `shrink` scales an icon longer than `MAX_SIDE` (1280 px) down on download — PNG when more than 1% of it is see-through, JPEG q88 otherwise; a smaller one is kept as it came. `store_icon` writes through a temporary file and removes a copy under another extension. `MAX_BYTES` (the download bound) is 16 MB. `shrink_cached_once` shrinks the existing cache once per server at start-up (`app_settings['achievement_icons_shrunk_1280']`), one file at a time (#210).

- `poller/publisher.py`: `Picture.cover` marks the cover candidates from `_backups`; in `_deliver` a gallery of two or more sent as one photo puts them first (owner, 2026-10-18; #209).

## Operations

- After the deploy, the bot logs `cached icons shrunk: N of M files, X MB saved`. On the VPS, expect `data/achievements` to fall from ~4 GB to a few hundred MB per server.
