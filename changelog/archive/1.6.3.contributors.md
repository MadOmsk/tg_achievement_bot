## Steam guides and patches

- Migration 069: `titles.steam_appid*`/`tips_checked_at`, `title_achievements.tip_*`, `steam_apps`, `game_patches`; repo mixin `bot/db/repo/_steam.py`.
- `bot/services/steam_extras.py` fills a game (appid, tips, patches) after `ensure_title_match` in the three fetchers, in a background task; `bot/poller/patch_refresh.py` re-reads played games' patches (`patch_refresh_hours`) and month-old tips (`TIPS_REFRESH_DAYS`), one game a tick. `steam_guides.py` / `steam_news.py` are network only.
- **Which lines are a tip is Haiku's call, never rules or word lists** (owner, 2026-10-01): `bot/services/translate/guide_tips.py` cuts a guide into blocks at the lines that are exactly an achievement's name and asks, per block, for line numbers only (`block § first § last`); the tip is those lines copied (`steam_guides.tip_from_lines`). A guide naming fewer than three achievements, one in another language (the model answers `SKIP`), and PlayStation's platinum are passed over. Guides are read lazily (`guides_of(..., stop_when=)`); the first that fills half of the game's achievements is the only one used. Needs the Anthropic key.
- Migration 070: `title_guide_reads (title_id, guide_id, fingerprint, answer)`. The fingerprint covers exactly what the prompt shows (guide lines, each achievement's shown name and description, both names for the name marks); the answer is the model's line ranges as JSON, cut into tips again on a hit — a guide asked once never costs another call, whether its tips were kept or not.
- In-memory guide cache: bounded (`_MEMORY_GUIDES`) and aged like the disk copy (a week). Steam 429 backs off 90 s, doubling to 15 min.
- Mini API: `GET /api/mini/games/{platform}/{title_id}/guides` never waits for a fill: it starts one in the background (`ensure_title`) and answers with what is stored and `complete: false`; the Mini App asks again. `/patches` reads the database.
- Webapp: `GameTabBar.tsx`, `PatchNotes.tsx`, tips in `GameAchievementRow.tsx`, `RichText.tsx` (links, videos, pictures, tables), `game-cache.ts`, `EmptyState` (an empty month); account icons back in `PlatformCard.tsx` (the "Posting" button is gone from the Mini App).

## Bot

- **One rarity threshold for every chat** (owner, 2026-10-01): `app_settings['rare_threshold_percent']`, default 10%, no per-chat override. The repo reads it wherever a chat's settings are read (`_sql.py::GLOBAL_RARE_THRESHOLD`), so callers still take `chat.rare_threshold_percent`; `chat_settings.rare_threshold_percent` is left unread. /admin: a row on the global settings screen (`a:rare`); the chat card lost it. The Mini App's chat PATCH still accepts it and sets the global value (#153 moves the field).
- **Hidden achievements** (#95): `views/panel.py::render_privacy_howto`, `panel:howto:steam` / `panel:howto:psn:<account_id>`; "Check again" is the backfill retry (`bf:steam`, `bf:psn:<id>`). `STEAM_PRIVACY_URL` moved to `services/profile_links.py`.
- **Start-up**: `bot.me()` is retried for about two minutes (`_ME_RETRY_DELAYS`); a run that raises before polling ends with `os._exit(1)`, so systemd restarts it instead of a process left waiting on an open aiosqlite thread.
