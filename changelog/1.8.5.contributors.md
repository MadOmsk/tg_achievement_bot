# 1.8.5 — notes for contributors

## Version

- A hotfix: `TRUNK_LINE` stays 8, no migration (D stays `089`), no new dependency.
- `services/release_notify.py::is_hotfix`: a release whose C is above 0 is announced as a hotfix (`main-release-hotfix`).

## Bot

- `services/post_picture.py`: a picture more than `SEE_THROUGH_SHARE` (10%) transparent is composed on the card whatever its size, at its own size, never enlarged (`is_see_through`, `_to_draw`). An opaque high-resolution picture still goes as it is; the `off` style is unchanged. With the `original` card size the ground under transparency is the icon's toned-down colour, not black (#197).
- `services/steam/client.py::_get`: a 401/403 with a JSON `playerstats` body raises `SteamGameDetailsPrivateError`; only a non-JSON one is `SteamKeyDeadError`. Steam answers a hidden profile's `GetPlayerAchievements` with 403 `{"playerstats":{"error":"Profile is not public"}}` (#198).
- `poller/steam_fetcher.py`: `achievements_visible = 0` now also means "the history waits". A backfill hidden on every game marks it and raises (the person gets `backfill-steam-private`); `poll_title` on a hidden profile returns 0; its first successful read, or a library answering `catch_up` / `refresh_user` while marked, starts `fill_library_gaps` in the background (`fill_in_background`, one per account). `fill_library_gaps` stops at its first hidden game. `LIBRARY_TOPUP_KEY` is `steam_library_topup_private`, so the startup top-up runs once more (#198).
- `services/api_usage.py`: every API's requests (Anthropic's tokens too) in memory for 24 hours; `views/admin_home.usage_rows` words the lines once for `/admin` and `/api/mini/admin` (`usage: [{label, value}]`) (#196).

## Operations

- After the deploy, `scripts/check_integrity.py --platform steam` should show no account missing anything but private ones.
