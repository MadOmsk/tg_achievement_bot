# 1.4.0 (1.3.1) — notes for contributors

Architectural updates, database schema changes, and infrastructure enhancements in release `1.4.0`.

## Trunk line bump to 4

- `bot/version.py`: `TRUNK_LINE` bumped from `3` to `4`.
- Tagged with `v1.4.0` on `main`.

## Database Schema & Migrations

- Migrations up to `056` applied:
  - Catalog schema enhancements for global achievements (`title_achievements` table).
  - Platform account link and deletion cooldown tracking.
  - Chat wrap-up scheduling configuration.

## Achievement Catalog Service

- Added `bot/services/catalog/` with 24-hour TTL caching for Xbox, Steam, and PSN title achievements.
- Added disk storage manager for achievement icons under `data/achievement_icons/<platform>/<title_id>/`.
- Integrated full catalog data into Mini App endpoints (`/api/games/{platform}/{title_id}`).

## Telegram UX Refactoring

- Separated chat hub presentation (`hub_text`, `chat-panel-text`) and command reference (`help_text`, `chat-help-text`).
- In `bot/handlers/panel.py`, restricted `panel_command` to `ChatType.PRIVATE`; group `/panel` falls through to `bot/handlers/chat.py`.
- Group command menu registered with `BotCommandScopeAllGroupChats` restricted to `["panel", "subscribe", "hltb", "help"]`.
- Added `bot/handlers/date_picker.py` implementing modular calendar navigation for `/stats` and `/summary_*`.

## Poller Optimization

- Implemented dormant player tiering (14-day inactivity threshold) across all pollers.
- Added Steam catch-up mechanism (`bot/poller/steam.py`) to prevent broadcast flood after downtime.
- Added PSN rate limiting and exit polling in `bot/poller/psn.py`.
- Unified sync handler (`bot/handlers/panel.py`) triggering concurrent multi-platform fetch and waking dormant players.

## Deploy & CI

- Auto-updating `xbox-deploy` script on target VPS host.
- Resolved SIGPIPE exit codes in CI pipeline journalctl verification.
