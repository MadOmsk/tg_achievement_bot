# 1.3.0 — 19 September 2026

Major update 1.3: the bot now announces new releases directly in group chats,
game icons in the Mini App are reliably served over HTTPS, and Xbox TitleHub
response parsing is resilient to upstream schema quirks.

## What's new

- **Release announcements in group chats.** Following every release, the bot
  automatically notifies active group chats about the update and attaches an
  inline button linking directly to the release notes in the chat's configured
  language (English or Russian). Routine server restarts remain silent as the bot
  remembers already-announced versions.
- **HTTPS game icons in Mini App.** Resolved an issue where older game icon URLs
  using plain HTTP were blocked by modern mobile WebViews due to mixed-content
  restrictions, causing blank images. All game icon URLs are now normalized to
  HTTPS.
- **Mini App visual polish.**
  - Improved layout of achievement cards, secret achievement spoilers, and carousels.
  - Optimized margins and spacing across the game gallery and friend rosters.
  - Proper alignment and sizing for user avatars.
- **TitleHub stability.** Fixed a crash when Microsoft's TitleHub returns null or
  unexpected types for `minAge`. Malformed upstream responses are now safely
  handled as cache misses without failing poller loops.
- **Changelog history.** Comprehensive release notes for previous releases have
  been compiled and added to the repository.

## For administrators & contributors

- `CLAUDE.md` now establishes an invariant release ceremony: all release notes
  must be drafted by AI agents in `test` before merging into `main`.
- Added `bot.services.release_notify` with rate-limiting, error handling, and
  per-chat locale targeting.
