# 1.6.2 — notes for contributors

## Deep link to a game

- `bot/services/mini_app.py`: the open-button helpers take `game: (platform, title_id) | None` and encode it as `g<platform>:<titleId>` in the `startapp` value (groups) or `g=platform:titleId` in the query (DMs). `bot/poller/publisher.py` passes `person_id` and the game for single publications and for a flood digest of exactly one game; `tests/test_publisher.py` asserts the exact start_param.
- `webapp/src/App.tsx` (`launchContext`) parses `g`, and `GameOpenProvider` seeds its state from `initialGame`.

## HLTB details

- Migration `064_hltb_details.sql` adds `hltb_cache.details` (one JSON object). `bot/services/hltb.py` fills it from the same `__NEXT_DATA__` read that already brings genre and description (`_extras_of`); rows cached before 064 are topped up once (`_top_up_details`). HLTB's counts of its own users are left out on purpose (CLAUDE.md, HowLongToBeat).
- `webapp/src/components/game/hltb-about/HltbAbout.tsx` renders the tab.

## Mini App

- `HeroPeek.tsx` collapses the game hero; heavy screens and `TitleSheet` are `React.lazy` (entry bundle 442 kB → 337 kB).
- Removed: the `/test_notify` command and `scripts/send_test_notifications.py`.
