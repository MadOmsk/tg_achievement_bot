# 1.2.4 — 19 September 2026

Four quick but important releases on production following the launch of the Mini
App: polished the interface, automated deployment with safety backups, gave the
test bot its own isolated web app, and tidied up game titles and build numbers.

## Mini App: UI polish

- **Glass blur in production builds.** Vite's CSS minifier was stripping
  unprefixed `backdrop-filter` rules and collapsing blur to zero. Production
  builds now retain the full frosted glass and blur effects on cards and bars.
- **Readable text over game art.** Game cards received a delicate frosted scrim
  under the text so titles remain easy to read regardless of the artwork behind
  them.
- **Tighter layout and title truncation.** Long game titles now truncate
  smoothly with an ellipsis at ~80% width without breaking the completion
  percentage or trophy counter alignment.
- **Smart club navigation.** Opening the app from a group takes you directly to
  that group's club. Opening it from a direct message prioritizes active and
  subscribed clubs rather than listing chats alphabetically.
- **"See all" games.** The profile screen now allows expanding the full games
  list rather than just the recent preview.
- **Polite empty states.** Profiles and chats without any unlocked achievements
  yet now display a clean trophy placeholder instead of an empty screen.
- **Reduced visual clutter.** Dropped the redundant "Open app" button from the
  DM onboarding text (the Telegram menu button already handles it). In groups,
  `/start` no longer attempts to send an invalid web_app inline button that
  caused Telegram errors.

## Automated deployment & test environment (#4)

- **Continuous integration on every push & PR.** GitHub Actions runs the full
  test suite (`pytest`), linter checks (`ruff`), and builds the TypeScript/Vite
  SPA before anything lands on `test` or `main`.
- **One-command safe deployment.** The server deploy script creates a fresh
  backup in `/var/backups/xbox-bot/` before every update, pulls changes, updates
  dependencies only when needed, and verifies the bot started and reported its
  version before marking the deploy complete.
- **Dedicated Mini App for the test bot.** The test environment now has its own
  domain at `test.xbox.sultanpharm.com/app/` on port 8081, allowing frontend
  changes to be reviewed on test database data without touching production.

## Game catalogue & database cleanup

- **Titles for 76 forgotten Xbox games.** Resolved a catalogue gap where games
  played in the past were never assigned names, leaving 658 achievements listed
  as "без названия" ("untitled"). Titles were backfilled from the Xbox Title Hub.
- **Missing platforms restored.** 125 historical catalogue rows with null
  platform fields were populated using adjacent achievement records.

## Honest version numbering

- `main` (production) is now automatically identified as `1.2.*`, while the test
  bot and other branches report `1.3.*`, without requiring manual code changes
  during release merges.
- Production build numbers now count actual releases (`--first-parent` merges)
  since `v1.2.0`. As a result, production in `/help` accurately introduces itself
  as **`1.2.4.050`** instead of staying at `1.2.0.050`.
