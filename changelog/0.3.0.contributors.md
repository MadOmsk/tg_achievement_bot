# 0.3.0 — notes for contributors

## Version

- **`0.B.C.D` until 1.0** (owner, 2026-10-31): the old major became the minor, so 2.2.1 reads 0.2.1. `MAJOR = 0`, `TRUNK_LINE` 2 → 3, tagged `v0.3.0`. C is a hotfix or a small update. Notes before this one are in `changelog/archive/`.
- New dependency: `psycopg[binary]`. `aiosqlite` is still listed until the cleanup after the switch.

## Database

- **PostgreSQL 16 (#234).** One database `unlocked`, schemas `prod`, `test` and the shared `games`; `search_path=<own>,games`. `bot/db/postgres.py` gives psycopg the connection the repo always spoke to; dates and JSON stay text, flags BIGINT 0/1.
- The schema is `bot/db/pg/app.sql` and `games.sql`; new migrations go in `bot/db/pg/migrations/`, numbered on from 146. A catalog migration must be additive and idempotent, `ADD COLUMN IF NOT EXISTS` written out: the other server stops at start-up otherwise. `bot/db/schema.sql` and `bot/db/migrations/` stay for the import tool only.
- **SQLite habits that break:** `? IS NULL` needs a cast, `IS x` is `IS NOT DISTINCT FROM`, bare `GROUP BY` columns, `json_each`, `rowid`, `INSERT OR …`. A failure inside a transaction block poisons the block, and `commit()` then raises.
- A bot refuses an empty schema (`EmptySchemaError`; `DATABASE_NEW_OK=true` for a new one) and exits when its connection is lost, for systemd to start it again.
- Migration 148: `pass_seen`, `season_notified`.

## Scripts

- Scripts open the database through `bot/db/tools.py` and take `--schema`. Run them with `-m`: a venv's editable install can point at another checkout. `scripts/sqlite_to_pg.py` moves a server: `bring-up`, `preflight`, `import`, `verify`.
- Gone: `games_db.py`, `catalog_transfer.py`, `bot/db/files.py`, the `backfill_*` one-offs.

## Bot

- **Translations** (#240): `GameTranslator` translates a game whole, through three doors: a page opened (`pending`, the Mini App's `.translating`), collection and the octopus (`later`), the queue (`poller/translations.py`, off by default, an action only a super-admin sees). `scripts/translate_batch.py` runs a share of the queue and prints its tokens, stopping at `--max-dollars`.
- **Season start** (#243): `poller/season_start.py`, the `season_start` notice. `POST /api/mini/pass/seen` marks the pass's own page opened.
- Roles (#232), a player's own PSN token (#233), polling steps as admin settings (#184 stage 0), time zones by place (`services/time_zones.py`).

## Operations

- Backups are `pg_dump` (`xbox-deploy`, 8 prod, 5 test) and daily (`unlocked-backup.timer`). `scripts/provision-postgres.sh` and `deploy/postgresql/` make the database. `games` belongs to `unlocked_games`, a role both bots are members of; an event trigger hands it whatever is made there.
- `xbox-deploy` installs a checkout's copy of itself only forward (`DEPLOY_SCRIPT_EDITION`).
- **Rollback within 48 hours:** the previous tag on SQLite and the untouched `bot.db`. What happened since the switch is lost.
- Known and open: the octopus fails when its anchor stand-in is replaced (#242).
