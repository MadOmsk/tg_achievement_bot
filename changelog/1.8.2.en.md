# 1.8.2 — 9 October 2026

Signing in with a passkey, and a new face for the app.

## Signing in

- **Passkeys.** Settings → Profile → Sign-in adds a passkey — your fingerprint or face. When an address has one, the app asks for the passkey instead of an emailed code; without it at hand, the code comes as before. Passkeys are listed and removed there too.
- **The name on the sign-in screen.** One word, "Unlocked", its "U" the icon's own, in place of a logo above a title.

## Chats

- **One digest size for every chat.** How many achievements make one grouped post is now one number for all chats (3 unless changed), set by the super-admin.
- **No more minimum gamerscore.** It held back every Steam and PlayStation achievement, which have no gamerscore at all; a chat that had one set now gets them like any other.

## Unlocked

- **The Android icon** is neater: a smaller "U", never cut off. The installed app starts on the bare "U" on a dark screen.
- **A game news notice** opens the post itself, not the game — from the bell and from a push.
- **The "Install Unlocked" banner** shows the bare "U", shorter words, the width of the dock.
- **A post's picture** is centred on a wide screen.
- **The trash icons in settings** sit flush with the row's edge.
