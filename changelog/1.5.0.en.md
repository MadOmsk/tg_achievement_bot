# 1.5.0 — 26 September 2026

A major Mini App update: game pages with complete achievement lists and player comparisons, monthly games in profiles, recent achievement showcases, day-jump calendars, skeleton loading screens, and an updated design.

## Mini App

- **Game page.** Tap any game block on an achievement card, in a profile gallery, or in the stats games list to open its full-screen game page: full-bleed cover art, completion progress, and every achievement. A lock toggles between earned and remaining items, while **"Compare"** displays marks for both players in a single list. Games completed to 100% feature a prominent platinum medal, rays of light, and edge shine. Full descriptions are preserved without truncation, and achievements without individual icons fall back to the game cover.
- **Profiles showcase games.** Below the gallery, profiles now feature the month's games sorted by most recent unlock. Each entry displays cover art, a progress bar (platinum-tinted at 100%), unlocked counts, and the latest unlock date. Tapping a game opens its page. Completed game covers feature a subtle periodic shine.
- **Recent achievements gallery.** The home screen and player profiles feature a carousel of up to five recent unlocks spanning the full width with prominent titles. Tapping a game jumps to its page.
- **Day calendar jump.** Date headers and labels ("Today", "Yesterday") in the feed and profiles open an interactive month calendar to jump straight to any selected day.
- **Smooth looping carousels.** Carousels in the feed and galleries run on Swiper with seamless loop pagination, responsive touch controls, and optimized rendering.
- **A lighter, responsive feed.** Posts load progressively as you scroll, images fade in smoothly as complete assets, and opening game pages leaves background feeds artifact-free.
- **Unified progress bars and tier medals.** All progress meters share a clean layout with 25%, 50%, and 75% tick marks and a soft glow. PSN trophy tiers (bronze, silver, gold, platinum) feature crisp vector badges.
- **Skeleton loading states.** Screens respond immediately with pulsing layout placeholders instead of spinning indicators.
- **Secret achievements.** Score, rarity, and game context remain visible while names and descriptions are blurred until tapped.
- **Account deletion and settings.** The settings screen includes a delete account button with native Telegram confirmation. Settings are organized into clear sections ("General", "Accounts", "Chats").
- **Typography.** Powered by the Inter typeface with improved legibility for secondary labels and aligned rarity values.

## Bot and stability

- **Test bot leaves production chats active.** When running the test server against a production database clone, chats the test bot is not a member of are skipped in memory rather than deactivated in the database.
- **PSN catalog.** Fixed background catalog refreshing for PlayStation titles in the Mini App.
