# 1.8.6 — notes for contributors

## Version

- A hotfix: `TRUNK_LINE` stays 8, no migration (D stays `089`), no new dependency.

## Bot

- `services/images.py::current_url` maps `steamcdn-a.akamaihd.net/steamcommunity/public/images/apps/` to `shared.fastly.steamstatic.com/community_assets/images/apps/`. A game released lately has no icon on the old host; every older one is on both. It is applied in `steam/client.get_schema`, the cached schema (`steam/achievements._schema`), `publisher._gallery`, `images.fetch` / `download`, `achievement_icons` downloads and `format_achievement_icon_url`. Stored rows keep the platform's address (#205).
- `poller/covers.py`: when both fixed Steam paths fail, `steam/client.store_header_url` reads `header_image` from `appdetails` (`filters=basic`, no key; shares `_store_basic` with `store_name`) and that is downloaded (#206).
