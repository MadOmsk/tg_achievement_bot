# 1.7.0 — notes for contributors

## Version

- A new minor: `TRUNK_LINE` goes to 7 and `main` is tagged `v1.7.0` (CLAUDE.md, Releases). The 1.6.2 notes were folded in here — 1.6.2 was never released.
- Migrations `063_rarity_to_person_digest_to_chat`, `064_account_publishes`, `064_hltb_details`, `065_untranslated_is_not_russian`, `066_several_psn_accounts`; D becomes `066`. Numbers repeat on purpose: migrations are keyed by file stem. Rehearse all five on a fresh copy of production before the merge.

## Accounts and the panel

- #126, migration 063: `user_settings.rarity_mode` (the mode a person used most) and `chat_settings.digest_threshold` (the size a chat used most); both subscription columns dropped.
- #20, migration 064: `account_links.publishes`, the person's switch per account. A muted account is still stored and counted; the publisher and the flood flush skip it.
- #10, migration 066: several PSN accounts per person (up to three). `/panel` has one row per platform (`views/keyboards.py::_platform_row`) and a screen per platform (`views/panel.py::render_account_menu`).
- Login rows: `panel-login-row` per platform, `visibility_status_text(..., with_time=False)`; ❗ on a Steam/PSN button while `achievements_visible` is false.
- Profile links: `app_settings['show_profile_links']` (`SHOW_LINKS_KEY`, default on), toggled in /admin → global settings; `user_settings.show_profile_links` is no longer read and `/api/mini/settings` no longer accepts it.
- Account-flow steps edit their own message and end in buttons (`views/keyboards.py::buttons`, `panel_button`, `back_to_panel_button`); the timezone picker opened from /panel uses the `ptz:` prefix and returns to the panel.
- Panel and account screens go out with `parse_mode=HTML` — the views escape every name they interpolate.
- #133/#139/#140: `settings_button()` in groups, `/promo` only, the four-command DM menu and `private_help_text()`.

## Backfill status

- `bot/handlers/backfill.py`: `run_xbox` / `run_steam` / `run_psn` own one status message, redrawn at most every `PROGRESS_INTERVAL` (5 s), ending as the result or a retry (`bf:xbox`, `bf:steam`, `bf:psn:<account_id>`). Each fetcher's `backfill(..., progress=)` reports `(done, total, found)` (`Progress` in `services/psn/achievements.py`); Xbox counts three steps, not games.

## Syncing and descriptions

- #91/#92: Xbox 360 history from contract 1 `/achievements` and `/history/titles`, topped up once at startup (`Fetcher.fill_x360_gaps_once`).
- #127, migration 065: a Russian description is trusted only with a `description_source`, and only when it reads as Russian (`util.looks_russian`); non-Cyrillic Russian sides are dropped and re-queued.
- #132: Steam secret descriptions from the profile page (`steam/client.py::community_descriptions`, `Steam_Language` cookie), at poll time and by the description walker.


## Deep link to a game

- `bot/services/mini_app.py`: the open-button helpers take `game: (platform, title_id) | None` and encode it as `g` + base64url(`platform:titleId`) in the `startapp` value (groups — Telegram allows only `[A-Za-z0-9_-]` there, #145) or `g=platform:titleId` in the query (DMs). `bot/poller/publisher.py` passes `person_id` and the game for single publications and for a flood digest of exactly one game; `tests/test_publisher.py` asserts the exact start_param.
- `webapp/src/App.tsx` (`launchContext`) parses `g`, and `GameOpenProvider` seeds its state from `initialGame`.

## HLTB details

- Migration `064_hltb_details.sql` adds `hltb_cache.details` (one JSON object). `bot/services/hltb.py` fills it from the same `__NEXT_DATA__` read that already brings genre and description (`_extras_of`); rows cached before 064 are topped up once (`_top_up_details`). HLTB's counts of its own users are left out on purpose (CLAUDE.md, HowLongToBeat).
- `webapp/src/components/game/hltb-about/HltbAbout.tsx` renders the tab.

## Mini App

- `HeroPeek.tsx` collapses the game hero; heavy screens and `TitleSheet` are `React.lazy` (entry bundle 442 kB → 337 kB).
- Removed: the `/test_notify` command and `scripts/send_test_notifications.py`.
