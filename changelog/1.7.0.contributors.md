# 1.7.0 — notes for contributors

## Version

- A new minor: bump `TRUNK_LINE` to 7 on `prerelease`, tag `v1.7.0` on the merge into `main`, push the tag first (see CLAUDE.md, Releases).
- Migrations `071_person_id`, `072_handles`, `073_follows`, `074_web_sessions`, `075_follow_notices`; D becomes `075`. Rehearse all five on a fresh copy of production before the merge. 071 rebuilds `users` with foreign keys off inside the script.

## People (#156, #157)

- `users.id` is the person's own id (071); `tg_id` stays unique and nullable, and every older table still points at `users(tg_id)`. New tables (`follows`, `blocks`, `web_sessions`) point at `users.id`.
- Nicknames (072): rules in `services/handles.py`, storage in `db/repo/_handles.py`. Everybody gets one at start-up (`give_everyone_a_handle`). Naming chain 1 of #51 is now nickname → username → platform nickname → id.
- Follows and blocks (073): `db/repo/_follows.py`, `services/people.py::can_view` (the one visibility rule), `web/mini_people.py`. Nobody removes a follower; one unfollows or blocks. `users.activity_visible` is the privacy setting.
- Scope: `?scope=following` on `/club/feed`, `/club/summary`, `/club/online`, answered by the chat queries through `_sql.member_source`. The game page shows another person's progress when their privacy allows, chat or not.
- Browser sign-in (074): `web/mini_session.py`, `mini_auth.validate_login_widget`; a request without Init Data falls back to the `ab_session` cookie. Each bot needs BotFather `/setdomain` for its Mini App host.

## Mini App

- `components/shared/lib/form-rows` — the one vocabulary of settings and admin screens; `components/shared/lib/dropdown` — every pick-one-of-a-list control; button rules in `styles/base.css` (CLAUDE.md, "Actions look one way each").
- New: `screens/people` (Search), `components/people` (`FollowButton`, `PersonSheet`), `components/club/follows-sheet`, `screens/login`. The HowLongToBeat search is back inside Search.
- The global rarity threshold moved from a chat's card to admin → Global rules (`/api/mini/admin/defaults`).
- Microsoft sign-in asks for `prompt=select_account`.
- `user_settings.notify_followers` (075): Settings → Notifications turns the new-follower DM off.
- Following and followers live in `components/club/follows-sheet` (Home → Friends → All), counted beside the title; the dropdown menu is frosted glass with no tick.
- Review fixes (owner, 2026-10-03): "everyone" sees a person's activity only from a shared active chat or a follow (`repo.can_view_activity`, also the game page's `?tg_id=`); people lists send `tg_id` only to who may see the activity; `follow_log` (076) — one follow DM per pair a day, a re-follow waits 10 minutes after an unfollow (429 `too_soon`); a nickname changes once a day, not 30.
- Custom avatars, review fixes: the server re-encodes the upload with Pillow (new dependency) to a ≤512 px JPEG without EXIF, `services/custom_avatars.py`; the body is read from the stream up to 2 MB (aiohttp's 1 MB `client_max_size` no longer answers first); deleting an account removes the picture; `/admin` user card «🖼 Сбросить аватар» (`a:avclr:`).
