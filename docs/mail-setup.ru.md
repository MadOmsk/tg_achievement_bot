# Почта на сервере: настройка

Для того, кто деплоит Unlocked на VPS. Займёт полчаса–час, большая часть — ожидание DNS.

## Зачем это нужно

Unlocked отправляет письма только с шестизначным кодом для входа по почте. Пока почта не настроена:

- на экране входа в браузере есть только Telegram, поля для почты нет;
- **новичок не может зарегистрироваться в браузере вообще**: регистрация идёт по почте или через Telegram с кодом приглашения;
- экран «Добавь почту» не показывается.

Бот, Mini App внутри Telegram и всё остальное работают и без почты.

## 1. Выберите, чем отправлять

Нужен любой SMTP-сервер. Писем мало: десятки в день на сообщество в 20–30 человек.

| Вариант | Когда подходит | Минусы |
|---|---|---|
| **Сервис для писем** — [Brevo](https://www.brevo.com) (300 писем в день бесплатно), [Resend](https://resend.com), [Mailgun](https://www.mailgun.com), Amazon SES | **Рекомендуется для прода.** Письма от своего домена, хорошо доходят. | Нужно подтвердить домен через DNS. |
| **Почтовый ящик** — Gmail, Яндекс, Mail.ru с паролем приложения | Быстро, для тестового сервера. | Отправитель — сам ящик; дневные лимиты; личный пароль на сервере. |
| **Свой Postfix на VPS** | Не советуем. | Хостинги часто закрывают порт 25, у нового IP нет репутации — письма попадают в спам. |

Дальше — на примере сервиса. Для ящика пропустите шаг 2 и возьмите SMTP-данные из его справки (Gmail: `smtp.gmail.com`, 587, пароль приложения из настроек безопасности Google).

## 2. Подтвердите домен

1. Зарегистрируйтесь в сервисе и добавьте домен, с которого пойдут письма: `sultanpharm.com`. Можно и поддомен, например `mail.sultanpharm.com`.
2. Сервис покажет DNS-записи. Добавьте их там, где управляется DNS домена (у регистратора — Spaceship/Namecheap — или в Cloudflare):
   - **SPF** — TXT-запись `v=spf1 include:… ~all`. Если SPF у домена уже есть, не создавайте вторую, а допишите `include:…` в существующую: две SPF-записи ломают обе.
   - **DKIM** — одна или несколько TXT или CNAME, имя вида `xxx._domainkey`.
   - **DMARC** — TXT на `_dmarc` со значением `v=DMARC1; p=none;`, если сервис не дал свою.
3. Подождите, пока сервис покажет «verified»: от минут до пары часов.

## 3. Получите SMTP-данные

В сервисе создайте SMTP-ключ (часто это раздел «SMTP & API»). Понадобятся:

- хост, например `smtp-relay.brevo.com`;
- порт: **587** (STARTTLS) или **465** (SSL);
- логин и пароль (SMTP-ключ).

Проверьте, что VPS выпускает наружу на этот порт:

```bash
timeout 5 bash -c '</dev/tcp/smtp-relay.brevo.com/587' && echo open || echo closed
```

Если `closed` — попробуйте 465 или спросите хостинг, не закрыт ли исходящий SMTP.

## 4. Впишите настройки в `.env`

Настройки лежат в файле окружения каждого бота:

| | прод | тестовый сервер |
|---|---|---|
| файл | `/opt/xbox_achievement_bot/.env` | `/opt/xbox_bot_test/.env.test` |
| сервис | `xbox-bot` | `xbox-bot-test` |

Редактируйте от пользователя бота, не от root:

```bash
sudo -u botsvc nano /opt/xbox_achievement_bot/.env
```

```ini
SMTP_HOST=smtp-relay.brevo.com
SMTP_PORT=587
SMTP_SECURITY=starttls        # starttls для 587, ssl для 465
SMTP_USERNAME=логин-из-сервиса
SMTP_PASSWORD=ключ-из-сервиса
SMTP_FROM=no-reply@sultanpharm.com

# Только для разработки. На сервере — false или строки нет вовсе.
EMAIL_LOG_CODES=false
EMAIL_SKIP_CODE=false
```

Важно:

- **`SMTP_FROM` — только адрес**, без имени («Unlocked <…>» не подойдёт): он же уходит в push-сервисы как контакт. Адрес должен быть на подтверждённом домене, у ящика — сам ящик.
- Без `SMTP_HOST` **или** `SMTP_FROM` почта считается выключенной.
- Пароль живёт только в `.env`. В GitHub и в CI его нет: деплой файл окружения не трогает.
- Для push нужен ещё `MINI_APP_URL` — он уже задан, если Mini App работает.

## 5. Перезапустите и проверьте

```bash
sudo systemctl restart xbox-bot          # xbox-bot-test для тестового
journalctl -u xbox-bot -n 50 --no-pager  # бот поднялся, ошибок про почту нет
curl -s https://xbox.sultanpharm.com/api/mini/auth/config
```

В ответе должно быть `"email": true`. Потом откройте Mini App в браузере в режиме инкогнито, введите свою почту — код должен прийти за несколько секунд. Заодно проверьте, что письмо не в спаме: [mail-tester.com](https://www.mail-tester.com) покажет, всё ли в порядке с SPF и DKIM.

## Если не работает

| Что видно | Что делать |
|---|---|
| `"email": false` | Пусты `SMTP_HOST` или `SMTP_FROM`, правился не тот файл или бот не перезапущен. |
| В приложении «не удалось отправить», в логе `sign-in code not sent: …` | Посмотрите текст ошибки: `535`/`Authentication` — неверный логин или ключ; таймаут — закрыт порт (шаг 3), попробуйте 465 с `SMTP_SECURITY=ssl`. |
| Письма уходят в спам | Домен не подтверждён до конца: проверьте SPF, DKIM и DMARC на mail-tester. |
| В логе `EMAIL_SKIP_CODE is ignored` | Уберите `EMAIL_SKIP_CODE` из `.env`: на сервере он не работает и только шумит. |

Чтобы сменить ключ, впишите новый в `.env` и перезапустите сервис.
