# Снятие интерфейса с работающей сборки

Собирает [docs/ui/captured_production.md](../../docs/ui/captured_production.md):
что бот **на самом деле** рисует — текст, инлайн-кнопки, картинки, — чтобы
макеты в `docs/ui/` было с чем сверять.

Ничего не отправляется и никуда не ходит по сети: поднимается настоящий
`Dispatcher` с настоящими роутерами и middleware, а `Bot` получает сессию,
которая записывает исходящий вызов Telegram вместо выполнения. База —
копия, и между экранами она откатывается к исходной (кнопка языка,
тумблеры и подписки иначе меняют данные, по которым рисуется следующий
экран).

Скрипты идут по коду того дерева, которое им передали: чтобы снять боевую
версию, сделай `git worktree add <dir> <боевой коммит>` и укажи его первым
аргументом.

```bash
# 1. Копия базы + окружение (боевой FERNET_KEY на машину разработки не
#    возим: общие ключи в копии перешифровываются заглушками, см. doc).
cp data/prod-dump.db /tmp/capture.db
cp /tmp/capture.db /tmp/pristine.db      # источник отката между экранами

# 2. Экраны, до которых доходят командой или кнопкой
PRISTINE_DB=/tmp/pristine.db python scripts/ui_capture/capture_screens.py \
    <дерево> /tmp/captured.json scripts/ui_capture/screens.json /tmp/.env.capture

# 3. Сообщения, которые бот шлёт сам: публикации, итоги, напоминания
python scripts/ui_capture/capture_posts.py \
    <дерево> /tmp/captured_posts.json /tmp/.env.capture

# 4. Разметка
python scripts/ui_capture/render_docs.py \
    docs/ui/captured_production.md /tmp/captured.json /tmp/captured_posts.json
```

`screens.json` — список снимаемых экранов: `id`, заголовок, команда или
callback_data, и чат, в котором это происходит. Новый экран добавляется
сюда строкой.

`.env.capture` — обычный `.env` с фиктивным `BOT_TOKEN` (никуда не уходит),
`ADMIN_TG_IDS` настоящего суперадмина, `DB_PATH` копии и любым валидным
`FERNET_KEY`.

Экран, которому нужен живой вызов платформы, снять нельзя — он попадёт в
документ как несобравшийся, с текстом ошибки. Это же поведение и ловит
настоящие поломки: так нашлись неработающие кнопки «Обновить» и «Сброс» в
карточке пользователя.
